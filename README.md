# JSON Formatter & Viewer

A simple, secure, and user-friendly web-based tool for formatting, minifying, validating, and viewing JSON and NDJSON data. All processing happens locally in your browser—your data never leaves your device.

---

## Features

- **Format and Validate JSON**: Beautify and validate your JSON or NDJSON instantly.
- **Minify JSON**: Compress JSON or NDJSON to a compact format.
- **Copy/Paste Support**: Easily copy or paste JSON data with one click.
- **Load from URL**: Fetch and load JSON from any public URL.
- **Tabbed Interface**: Switch between raw text and formatted view.
- **Secure Local Processing**: No data is sent to any server; everything runs in your browser.
- **Keyboard Shortcuts**: Modal dialogs support Enter/Escape for quick actions.

---

## Getting Started

1. **Clone or Download** this repository.
2. Open `index.html` in your web browser. No build step or server required.

---

## Usage

- **Paste** your JSON or NDJSON into the textarea.
- Click **Format JSON** to beautify and validate.
- Click **Minify** to compress the data.
- Use **Copy** and **Paste** buttons for clipboard operations.
- Click **Load JSON** to fetch data from a URL.
- Switch between **Text** and **View** tabs to see raw or formatted output.
- Click **About** for more information and contact details.

---

## File Structure

- `index.html` – Main HTML file containing the UI and all JavaScript logic.
- `styles.css` – CSS file for styling the application.

---

## Security & Privacy

- **All processing is local**: No data is sent to any server.
- **Clipboard access**: Uses browser APIs for copy/paste. Permissions may be required.
- **No tracking or analytics**: This tool does not collect or store any user data.
